#GitHub SSO API Project (Java, SpringBoot, OAuth2, Thymeleaf)

-Configured Spring Security with OAuth2. Handled user details and processed OAuth2 tokens.
-Utilized SpringBoot to structure a modular backend
-Developed RESTful APIs using Spring WebClient to interact with GitHub's API,  retrieving user data. 
-Employed Thymeleaf templates  to dynamically render GitHub user information on the frontend.
